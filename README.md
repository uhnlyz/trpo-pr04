# Практическая работа № 4 — PHP: основы языка и обработка HTML-форм

## Результат
Учебное приложение для работы с данными сотрудников. Страница читает `employees.csv`, показывает таблицу, фильтрует её по отделу через GET и обрабатывает форму заявки через POST.

## Реализовано по заданию
- PHP-точка входа `public/index.php`, вывод версии приложения и текущей даты.
- Чтение `dataset/employees.csv` функцией `fgetcsv()` с разделителем `;`.
- Преобразование строк CSV в массивы сотрудников отдельной функцией.
- Таблица сотрудников и GET-фильтр по отделу.
- POST-форма с четырьмя полями: ФИО, email, отдел и опыт.
- Серверная проверка обязательных полей, email, длины имени и диапазона опыта.
- При ошибке введённые значения остаются в форме, сообщения показываются пользователю.
- Безопасный вывод через `htmlspecialchars()`.
- Чтение `form_cases.json` и автоматическая проверка трёх заданных сценариев.
- Функции обработки данных вынесены в `src/functions.php`.

## Требования и запуск
Нужен PHP 8.0 или новее. Composer и сторонние библиотеки не нужны.
Из корня проекта выполните:
```bash
php -S localhost:8000 -t public
```
Откройте `http://localhost:8000`. Остановить сервер можно через `Ctrl + C`.

## Проверка
1. В таблице должны отображаться пять сотрудников из CSV.
2. Выберите отдел в фильтре: в адресной строке появится GET-параметр `department`.
3. Отправьте пустую форму или некорректный email: PHP покажет ошибки, введённые значения сохранятся.
4. Введите корректные данные: появится подтверждение проверки заявки.
5. В блоке сценариев должны быть пройдены три проверки из `form_cases.json`.

## Как проходят данные через приложение

`employees.csv` → `loadEmployees()` → `normalizeEmployee()` → массив сотрудников → HTML-таблица.

Для фильтра браузер отправляет GET-параметр `department`; он виден в адресной строке и не меняет данные. Форма отправляет значения методом POST. PHP получает их через `$_POST`, нормализует с помощью `trim()`, проверяет и формирует HTML-ответ.

`htmlspecialchars()` нужен для безопасного вывода пользовательского текста: специальные символы преобразуются в HTML-сущности, поэтому введённая строка отображается как текст, а не как разметка.

## Ограничение
Форма демонстрирует серверную обработку и валидацию. Новая заявка не сохраняется в CSV и не отправляется на внешний сервер — для текущего учебного результата достаточно обработки данных и формирования ответа.
