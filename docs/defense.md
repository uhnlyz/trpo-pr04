# Подготовка к защите — практическая работа № 4

## Что показать
1. Запустить `php -S localhost:8000 -t public`.
2. Показать версию приложения и дату, сформированные PHP.
3. Открыть таблицу сотрудников и `dataset/employees.csv`.
4. Показать GET-фильтр отдела.
5. Отправить пустую форму и форму с некорректным email.
6. Показать, что введённые значения сохраняются после ошибки.
7. Отправить корректную форму и показать сценарии из `form_cases.json`.

## Термины простыми словами
- **PHP** — серверный язык: код выполняется на сервере, браузер получает готовый HTML.
- **GET** — параметры передаются в адресной строке; здесь так работает фильтр отдела.
- **POST** — данные формы передаются в теле запроса.
- **`$_GET` и `$_POST`** — массивы PHP с параметрами запроса.
- **`trim()`** — убирает пробелы по краям строки.
- **`filter_var()`** — здесь проверяет формат email.
- **`fgetcsv()`** — читает строку CSV и разделяет её на поля.
- **`htmlspecialchars()`** — безопасно выводит текст, не позволяя браузеру принять его за HTML.
- **Массив ошибок** — хранит сообщения проверки по полям.

## Контрольные вопросы
**1. Какие входные данные получает приложение и где они находятся?**  
Сотрудники находятся в `dataset/employees.csv`, тестовые сценарии — в `dataset/form_cases.json`. Пользователь отправляет поля формы через POST и выбирает отдел через GET.

**2. Какой участок кода отвечает за преобразование данных в интерфейс?**  
`loadEmployees()` читает CSV, `normalizeEmployee()` формирует структуру сотрудника, а `public/index.php` выводит массив в таблицу.

**3. Какое ошибочное состояние проверялось?**  
Пустое имя, некорректный email, отсутствующий отдел, отрицательный или слишком большой опыт.

**4. Что можно изменить при увеличении проекта?**  
Вынести POST-обработку отдельно, добавить класс сотрудника, хранить заявки в базе данных и разделить шаблон и обработчик.

**5. Как проверить работу после клонирования?**  
Установить PHP 8.0+, выполнить команду запуска из README и открыть `http://localhost:8000`.

**6. Чем PHP отличается от JavaScript в браузере?**  
PHP выполняется на сервере до отправки страницы. JavaScript в браузере выполняется на стороне клиента.

**7. Когда полезен конструктор класса?**  
Когда объект нужно создать с обязательными начальными значениями. Классы подробно рассматриваются в следующей практической работе.
